# 创作者画像 (Creator Profile)

## 1. 基础信息
- **身份**：全职自媒体转型者，前大数据推荐策略产品经理，36岁，ENTP
- **赛道**：AI × 个人品牌 × 内容创业 × 超级个体

## 2. 内容定位
- **核心身份**：现代哲学思考者 + 一人企业实践者 + 超级个体认知行为教练
- **人设基调**：走在前面一点的同路人——不是导师，是共同探索者
- **内容风格**：深度但不晦涩，高信息密度，敢挑战常识，真诚展示脆弱
- **差异化**：不仅教如何理解AI和赚钱，更教如何通过构建真实稳定的自我与他人协作，在AI时代生存

## 3. 目标受众
- **转型者（Marcus）**：想从打工转向自由职业/创业的人，35岁危机核心群体
- **探索者（Lily/Z世代）**：对AI、个人品牌感兴趣但缺乏认知和路径的人
- **觉醒者**：对996不满，渴望意义和精神自由的人
- **年龄段**：25-40岁

## 4. 内容形式优先级
1. 抖音 → 口播+特效短视频（60-180秒）
2. 小红书 → 图文笔记 + 短视频
3. B站 → 深度中长视频（10分钟以上）
4. 视频号 → 复用抖音内容为主
