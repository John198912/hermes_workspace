## 根因

报告生成步骤（Step 7）直接写入 `report_daily_YYYY-MM-DD.md`，没有任何版本检查逻辑。同日多次运行时，后续运行无条件覆盖已有文件。

**关键问题**：上午版和下午版**数据源不同**：
- 上午版：AI HOT 可用（中国AI圈全景） + 多源采集
- 下午版：AI HOT 失效（仅 Brave News + 搜狗微信替代）

覆盖下午版 = 丢失上午版独有的 AI HOT 数据（中国AI圈动态、OPC共创节、工信部风险提示等）。

---

## 修复

已在 `SKILL.md` 核心原则 #16 添加 AM/PM 版本保留规则：

```
1. 写入前检查目标文件是否存在
2. 存在 → 重命名为 _am.md（如尚无上午版）
3. 新报告写为当日版本 → 更新软链接
4. 如上午和下午均已存在且第三次运行 → 写为 _pm_v2.md
```

---

## 恢复操作

```bash
# 从 git 历史恢复两个版本
git show 1aa6b9c:reports/hotspot/report_daily_2026-07-08.md > report_daily_2026-07-08_am.md  # 上午版 402行
git show bc55593:reports/hotspot/report_daily_2026-07-08.md > report_daily_2026-07-08_pm.md  # 下午版 368行
cp report_daily_2026-07-08_pm.md report_daily_2026-07-08.md  # 当前版=下午版
ln -sf report_daily_2026-07-08.md report_daily.md  # 软链接
```
