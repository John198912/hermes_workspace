# 框架污染诊断模式 · Theory Neutrality Diagnostic

> **创建时间：** 2026-07-07
> **背景：** 用户发现每日采集报告受赵汀阳思想影响过重，要求定位渗入路径并解除
> **适用场景：** 当采集报告出现哲学家署名引用、理论术语渗透、或分析结构被单一理论框架主导时

---

## 一、问题描述

采集报告（日报/周报/素材深挖报告）中出现大量哲学家署名引用和理论术语：
- 选题标题直接写"赵汀阳 correlate 实证"
- 选题执行步骤内置"连接SOUL：赵汀阳correlate vs understand"
- 八层恐惧分析第5/6/8层强制使用赵汀阳理论
- 结构归因第5项固定为"Token源头转移（赵汀阳）"

## 二、渗入路径诊断

赵汀阳思想**没有显式写入任何采集配置文件**（搜索"赵汀阳"在 hotspot-research skill 中命中数为0）。它通过三条间接路径渗入：

| # | 路径 | 机制 | 证据 |
|---|------|------|------|
| ① | **System Prompt 直接注入** | Hermes system prompt 开头包含完整 SOUL 身份铭牌+知识图谱（赵汀阳占核心位置）。每个 cron session 的 LLM 都带着这个 system prompt 启动 | system prompt 第二节"灵魂宣言"+ 第五节"知识图谱" |
| ② | **报告模板标签** | `report_template.md` 标注"SOUL 框架赋能"+ 深度分析段有"SOUL 框架关联"字段 → 引导 LLM 调用 SOUL 框架（=赵汀阳概念） | `templates/report_template.md` 第3行 + 深度分析模板 |
| ③ | **人设标签** | `creator_profile.md` 写"核心身份：现代哲学思考者" → "哲学思考者"标签激活 LLM 从 system prompt 的 SOUL 知识图谱中提取赵汀阳概念 | `references/creator_profile.md` 第2节 |

### 诊断方法

1. **搜索哲学家名字**：在 `~/.hermes/skills/hotspot-research/` 和 `~/hermes_workspace/reports/` 中搜索"赵汀阳"等哲学家名字
2. **区分配置文件 vs 输出文件**：配置文件中命中=显式写入；输出文件中命中但配置文件不命中=间接渗入
3. **追溯 system prompt**：检查 system prompt 是否包含理论框架引用（SOUL 知识图谱）
4. **检查模板标签**：报告模板中是否有"SOUL框架""哲学思考者"等标签

## 四、核心原则

**阶段边界原则：**
- **采集阶段**（日报/周报/素材深挖）：理论中立，描述事实、数据、争议、受众痛点，不署名引用哲学家
- **创作阶段**（SOUL 对话/深度分析文档/内容生产）：引入理论框架，匹配最锐利的透镜，受"理论多元性原则"约束

**为什么采集阶段要中立？**
- 采集报告是信息输入，不是内容输出
- 预设框架会过滤掉不符合框架的信号（确认偏误）
- 不同话题需要不同透镜，预设框架限制了分析灵活性
- 理论框架是卷哥作为创作者的选择权，不应由采集流程自动决定

## 五、校准检查项（Step F 简表）

| 检查项 | 具体做法 | 常见陷阱 |
|--------|---------|---------|
| 哲学家署名引用 | 搜索"赵汀阳""Foucault""Heidegger""Han"等名字——出现即标记删除 | 选题标题直接写"赵汀阳 correlate 实证" |
| 理论术语渗透 | 搜索"自反性""correlate""有限性时间""token的源头""公共统治""动词哲学"——替换为事实描述 | "这正是赵汀阳动词哲学的实证"→"女性AI使用率低25%是能力惩罚的理性回应" |
| 选题框架预设 | 选题执行步骤不应预设理论框架 | "连接SOUL：赵汀阳correlate vs understand"→"连接受众痛点：AI不理解你的语境" |
| 结构归因多样性 | 每个归因项不应固定指向同一理论家 | 五结构归因第5项固定为"Token源头转移（赵汀阳）"→改为基于事实的归因 |

## 六、泛化：其他框架污染场景

此诊断模式不限于赵汀阳。任何理论框架（CBT、Bourdieu场域、McKee叙事理论等）如果通过 system prompt 或模板标签间接渗入采集报告，都适用同样的诊断和修复流程：

1. 搜索理论家名字 → 确认是否在配置文件中显式写入
2. 如不是 → 检查 system prompt 知识图谱、模板标签、人设标签
3. 修复 → 删除标签+加中立性纪律+加校准检查项
