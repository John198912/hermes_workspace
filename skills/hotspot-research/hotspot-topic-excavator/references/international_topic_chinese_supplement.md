# 国际治理话题·中文信源补强模式

> **来源**：2026-07-05 UN Women AI 性别偏见报告深挖实战
> **核心教训**：Brave/Tavily 对国际治理话题的中文信源覆盖存在系统性盲区
> **v2.5.0 强制规则**：国际治理话题 → 豆包搜索（byted-web-search）不可省略

---

## 一、问题诊断：Brave/Tavily 对中文治理信源覆盖弱

### 实证对比（2026-07-05 UN Women 报告案例）

| 维度 | Brave + Tavily 英文搜索 | 豆包搜索（byted-web-search）中文 |
|------|------------------------|--------------------------------|
| 命中数量 | 13 篇 | 5 条核心 + 多条次级 |
| 信源类型 | 英文媒体（NDTV/Forbes/Fortune/Euronews/Guardian）+ 印度媒体 | 中文官方（央行/中国日报/民主与法制）+ 中文深度评论 |
| 政策视角 | 缺失 | **央行三部门 2026-06-23 发文**「谨防 AI 性别偏见」 |
| 学术视角 | 仅有 Berkeley Haas + HBS | **达沃斯夏季论坛**「她视角」专题（全球女性 AI 研发仅 22%） |
| 案例细节 | 仅引用 Llama 2 概括 | **「花园 vs 宝藏」**Llama 2 故事生成完整对比（男孩 = 宝藏/海洋/冒险 vs 女孩 = 花园/爱情/丈夫） |
| 中国本土案例 | 零 | **蚂蚁集团 55% 女性设计师**医疗 AI 优化案例 |

### 根因分析

**Brave/Tavily 对中文信源的覆盖盲区有三层**：
1. **索引层**：中文媒体（央行/中国日报/民主与法制/今日头条深度报道）不在 Brave/Tavily 主索引优先级
2. **语言层**：即使中英文双语报道，Brave 优先返回英文版本（NDTV India 报道 > 21 世纪经济报道中国报道）
3. **政策层**：中国监管/政策类内容（央行/工信部/网信办）的英文转译往往延迟 3-7 天，且关键细节失真

**结果**：当 SOUL 受众主要是中文用户时，仅用 Brave/Tavily 会系统性丢失**中文政策语境 + 中国本土案例 + 中文叙事钩子**——这些恰恰是高共鸣素材。

## 二、触发条件：何时必须调用豆包搜索

### 必须调用（强制）

当锚点话题满足以下**任一条件**：

| 条件 | 案例 |
|------|------|
| **联合国/国际组织报告** | UN Women、UNESCO、WHO、IMF、World Bank |
| **跨国治理框架** | EU AI Act、AI for Good Summit、Paris Call、Bletchley Declaration |
| **全球行业事件** | Davos、WEF、G7/G20 AI 议题、AI Safety Summit |
| **跨境监管动作** | 美国出口管制、欧盟合规、中国网信办/工信部 |
| **全球统计数据** | 涉及「全球/跨国/国际」的研究、调查、指数 |

### 选择性调用

- **跨国企业事件**（如 OpenAI/Anthropic 政策变化）：豆包通常没有独特价值，可跳过
- **纯技术话题**（如新模型发布、新论文）：豆包价值低，可跳过
- **西方文化特定话题**（如好莱坞行业事件）：豆包价值低，可跳过

### 调用次数建议

| 话题类型 | 豆包组数 | 关键词设计 |
|---------|---------|-----------|
| 联合国报告类 | 1-2 组 | 「联合国 + 话题 + 报告 + 2026」+ 「中文媒体 + 话题 + 深度分析」 |
| 跨国治理类 | 2-3 组 | 「国家 + 话题 + 政策」+ 「中国 + 话题 + 影响」+ 「中文专家 + 话题 + 评论」 |
| 达沃斯/全球峰会 | 1-2 组 | 「达沃斯 + 话题 + 她视角/他视角」+ 「中国代表 + 话题 + 发言」 |

## 四、中文补强素材的处理方式

### 信息分层原则

| 来源类型 | 优先级 | 处理方式 |
|---------|--------|---------|
| **中国政府/央行/网信办官方发文** | 🔴 P1（高优先级） | 标注发文机构+日期+原文链接，可直接引用 |
| **权威媒体（21世纪经济报道/中国日报/新华社）** | 🔴 P1 | 标注媒体等级 + 关键段落原文 |
| **达沃斯/世界互联网大会等国际会议中文报道** | 🟡 P2 | 标注会议名称+嘉宾姓名+金句中英文 |
| **行业自媒体深度评论**（民主与法制/钛媒体/36氪） | 🟡 P2 | 标注作者 + 评论核心论点 |
| **知乎/小红书等 UGC 讨论** | 🟢 P3 | 仅作受众共鸣参考，不作论证素材 |

### 在报告中的呈现方式

**不要单独章节**：「中国视角」单独成章会割裂报告整体性。

**应该融入主线**：将中文独有视角作为**论据之一**自然嵌入相应模块：

```
例：UN Women 报告深挖报告中的处理
- 「三、权威引述」中混合中英文引述
  - 英文：Wickramanayake (UN Women)
  - 中文：央行三部门发文（21世纪经济报道 2026-06-23）
  - 中文：达沃斯嘉宾芭芭拉·卢茨（"如果今天女性缺席 AI 领导层..."）
- 「五、对立张力」中用中国数据补充
  - 反方：「AI 加速女性赋权」→ 中国数据反驳：女性岗位被自动化取代概率 2 倍
- 「四、案例故事」中嵌入中国案例
  - 故事 2：达沃斯「她视角」医疗 AI 案例 → 蚂蚁集团 55% 女性设计师
```

### 中文素材的可信度校验

| 校验项 | 操作 |
|--------|------|
| **官方原文链接** | 央行/网信办/工信部发文必须有原始 URL（gov.cn / pbc.gov.cn / cac.gov.cn） |
| **作者署名** | 自媒体深度评论必须有作者署名 + 媒体背景 |
| **交叉验证** | 关键数据（如「全球女性 AI 研发 22%」）必须有 ≥ 2 个中文源交叉 |
| **时间戳** | 中文报道往往比英文慢 1-3 天，标注发布时间避免时序混乱 |

## 五、与其他数据源的协作模式

```
                ┌─ Brave LLM Context（英文核心一手）
                ├─ Brave News Search（英文媒体矩阵）
                ├─ Brave Web Search（英文交叉验证）
                ├─ Tavily（英文深度 + 摘要）
Step 2A 组合 ──┼─ Jina Reader（一手原文提取） ←─── 见 references/jina_ssl_bypass.md
                ├─ 🆕 豆包搜索（中文信源补强） ←── 本文件核心
                ├─ AI HOT（中文 AI 圈内动态）
                └─ Python 引擎（可选）
```

### 调用顺序建议

1. **第一轮（广度）**：Brave News + Brave LLM Context + 豆包第 1 组（三组并行）
2. **第二轮（深度）**：Tavily advanced + Jina 一手原文 + 豆包第 2 组
3. **第三轮（发散）**：Brave web 发散 + 豆包发散（如有需要）

### 豆包搜索 vs AI HOT 的取舍

| 维度 | 豆包搜索 | AI HOT |
|------|---------|--------|
| **覆盖类型** | 全网（媒体+政策+评论+UGC） | 仅 AI 行业内 |
| **适用话题** | 国际治理/政策/社会议题 | AI 技术/产品/论文 |
| **中文报告类** | ✅ 央行/网信办等官方 | ❌ 不覆盖 |
| **AI 产品类** | ⚠️ 偶有命中 | ✅ 主力源 |
| **响应速度** | ~1s | ~6-8s |

**判断规则**：
- 国际治理/政策话题 → **豆包优先**，AI HOT 辅助
- AI 产品/技术话题 → **AI HOT 优先**，豆包辅助
- 双重维度话题 → 双源并行

## 六、反模式（不要做）

### ❌ 反模式 1：豆包搜索英文关键词

```
错误：python3 web_search.py "UN Women AI bias report" --time-range OneMonth
正确：python3 web_search.py "联合国妇女署 AI 性别偏见 报告 2026"
```

**根因**：豆包对中文关键词的匹配度远高于英文关键词——即使话题是国际新闻，中文搜索仍优于英文搜索豆包。

### ❌ 反模式 2：把中文独有视角当 P3 处理

```
错误：把所有豆包结果归类为「行业背景」P3，不进入深度分析
正确：央行三部门发文、达沃斯论坛等中文独有政策/学术视角，必须提升为 P1/P2
```

**根因**：中文政策语境对 SOUL 中文受众是高共鸣素材——不能因为信源是中文就降级。

### ❌ 反模式 3：忽略中文信源的时效延迟

```
错误：英文报道 6/22 + 中文报道 6/24 → 直接写「同日发布」
正确：标注中文报道发布日期 6/24，与英文 6/22 间隔 2 天
```

**根因**：中文媒体翻译/转载国际新闻有 1-3 天延迟，混用时间戳会造成「同日共振」假象。
