> **来源**：2026-07-05 UN Women AI 性别偏见报告深挖实战
> **核心教训**：WebSearch 对国际治理话题的中文信源覆盖存在系统性盲区
> **v2.5.0 强制规则**：国际治理话题 → 中文关键词搜索不可省略
> **Qoder 工具适配版**：原 豆包 → WebSearch（中文关键词）；原 Brave → WebSearch（英文）；原 Jina → WebFetch

## 一、问题诊断：英文搜索对中文治理信源覆盖弱

### 实证对比（2026-07-05 UN Women 报告案例）

| 维度 | 英文搜索 | 中文关键词搜索 |
|------|--------|--------------------------------|
| 命中数量 | 13 篇 | 5 条核心 + 多条次级 |
| 信源类型 | 英文媒体 + 印度媒体 | 中文官方（央行/中国日报/民主与法制）+ 中文深度评论 |
| 政策视角 | 缺失 | **央行三部门 2026-06-23 发文**「谨防 AI 性别偏见」 |
| 学术视角 | 仅有 Berkeley Haas + HBS | **达沃斯夏季论坛**「她视角」专题（全球女性 AI 研发仅 22%） |
| 案例细节 | 仅引用 Llama 2 概括 | **「花园 vs 宝藏」**Llama 2 故事生成完整对比 |
| 中国本土案例 | 零 | **蚂蚁集团 55% 女性设计师**医疗 AI 优化案例 |

### 根因分析

**英文搜索对中文信源的覆盖盲区有三层**：
1. **索引层**：中文媒体不在英文搜索主索引优先级
2. **语言层**：即使中英文双语报道，英文搜索优先返回英文版本
3. **政策层**：中国监管/政策类内容的英文转译往往延迟 3-7 天，且关键细节失真

## 二、触发条件：何时必须调用中文搜索

### 必须调用（强制）

| 条件 | 案例 |
|------|------|
| **联合国/国际组织报告** | UN Women、UNESCO、WHO、IMF、World Bank |
| **跨国治理框架** | EU AI Act、AI for Good Summit、Paris Call、Bletchley Declaration |
| **全球行业事件** | Davos、WEF、G7/G20 AI 议题、AI Safety Summit |
| **跨境监管动作** | 美国出口管制、欧盟合规、中国网信办/工信部 |
| **全球统计数据** | 涉及「全球/跨国/国际」的研究、调查、指数 |

### 调用次数建议

| 话题类型 | 中文搜索组数 | 关键词设计 |
|---------|---------|-----------|
| 联合国报告类 | 1-2 组 | 「联合国 + 话题 + 报告 + 2026」+ 「中文媒体 + 话题 + 深度分析」 |
| 跨国治理类 | 2-3 组 | 「国家 + 话题 + 政策」+ 「中国 + 话题 + 影响」+ 「中文专家 + 话题 + 评论」 |
| 达沃斯/全球峰会 | 1-2 组 | 「达沃斯 + 话题 + 她视角/他视角」+ 「中国代表 + 话题 + 发言」 |

## 三、搜索命令模板

### 基础调用

```
# 国际治理话题·中文视角第 1 组：政策 + 报告
WebSearch(query="[话题中文名] [报告/政策/法规] [年份]")

# 国际治理话题·中文视角第 2 组：本土案例 + 中国影响
WebSearch(query="中国 [话题中文名] [影响/案例/企业]")
```

### 实战关键词模板（UN Women 性别偏见案例）

```
# 第 1 组：直接锚定 UN Women 中文报道
WebSearch(query="联合国妇女署 AI 性别偏见 报告 2026")

# 第 2 组：中文政策/官方角度
WebSearch(query="AI 性别偏见 中国 政策 央行")
```

**实测产出**：第 1 组命中 5 条核心（搜狐/今日头条/民主与法制/财富号/中国日报）；第 2 组命中中国官方+学术+企业级深度内容。

## 四、中文补强素材的处理方式

### 信息分层原则

| 来源类型 | 优先级 | 处理方式 |
|---------|--------|---------|
| **中国政府/央行/网信办官方发文** | 🔴 P1 | 标注发文机构+日期+原文链接，可直接引用 |
| **权威媒体（21世纪经济报道/中国日报/新华社）** | 🔴 P1 | 标注媒体等级 + 关键段落原文 |
| **达沃斯/世界互联网大会等国际会议中文报道** | 🟡 P2 | 标注会议名称+嘉宾姓名+金句中英文 |
| **行业自媒体深度评论** | 🟡 P2 | 标注作者 + 评论核心论点 |
| **知乎/小红书等 UGC 讨论** | 🟢 P3 | 仅作受众共鸣参考 |

### 在报告中的呈现方式

**不要单独章节**——将中文独有视角作为**论据之一**自然嵌入相应模块。

### 中文素材的可信度校验

| 校验项 | 操作 |
|--------|------|
| **官方原文链接** | 央行/网信办/工信部发文必须有原始 URL |
| **作者署名** | 自媒体深度评论必须有作者署名 + 媒体背景 |
| **交叉验证** | 关键数据必须有 ≥ 2 个中文源交叉 |
| **时间戳** | 中文报道往往比英文慢 1-3 天，标注发布时间 |

## 五、反模式

### ❌ 反模式 1：中文搜索用英文关键词
正确做法：用中文关键词，匹配度远高于英文

### ❌ 反模式 2：把中文独有视角当 P3 处理
正确做法：央行三部门发文、达沃斯论坛等中文独有政策/学术视角，必须提升为 P1/P2

### ❌ 反模式 3：忽略中文信源的时效延迟
正确做法：标注中文报道发布日期，避免「同日共振」假象
