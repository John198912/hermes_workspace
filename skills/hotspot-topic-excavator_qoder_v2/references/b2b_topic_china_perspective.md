# B端/商业话题·中国视角补强模式

> **来源**：2026-07-05 B 端公司 AI 化改造升级（微软 Frontier Company）深挖
> **核心教训**：「中国视角」≠「国际治理话题中文补强」——B2B/商业话题走完全不同的检索逻辑
> **v2.6.1 强制规则**：B 端公司/商业/产业/经济类话题 → 中文关键词搜索 8 组广覆盖（默认）+ 必须引用政策驱动力 + 必须给中美对比矩阵
> **Qoder 工具适配版**：原 豆包 byted-web-search → WebSearch（中文关键词）；原 Brave → WebSearch（英文）

## 一、与「国际治理话题中文补强」的边界区分

| 维度 | 国际治理话题（已有） | B 端公司/商业话题（本文件） |
|------|--------------------|---------------------------|
| 锚点类型 | UN/WHO/IMF/EU 等多边机构 | 跨国 AI 厂商/Microsoft/AWS/OpenAI 等 |
| 核心补强 | 中国监管/政策/学术本土视角 | 中国政策驱动力 + 中国 AI 厂商路线 + 中国制造业实证 + 中美模式对比 |
| 中文搜索组数 | 1-2 组 | **8 组关键词广覆盖** |
| Layer 2 处理 | 中文素材自然嵌入主线 | **必须重写主选题为"全球-美国-中国"三段式** |
| 适用锚点示例 | UN Women AI 偏见报告 | Microsoft Frontier Company · 微软裁员 · Anthropic Agent SDK |

## 三、采集顺序（必须按此顺序）

```
【1】先确认锚点：WebSearch 英文搜索拉取核心信源（微软/四巨头原文）
    ↓
【2】补强英文深度：WebSearch + 时效搜索（MIT NANDA / 行业分析）
    ↓
【3】中文搜索第 1-2 组（政策 + 大厂路径）：拉取中国 B 端政策+主流厂商路线
   ↓
【4】中文搜索第 3-4 组（本土实证 + 案例）：制造业/咨询业/Agent 实证
   ↓
【5】中文搜索第 5-6 组（路径对比 + 调用量）：中美路线 + 市场份额数据
   ↓
【6】中文搜索第 7-8 组（基础设施 + 竞争）：云厂资本 / 中美 AI 投入
   ↓
【7】整理 → Layer 2 重写为三段式 → 校准记录增 3 项
```

## 四、8 组中文关键词模板

## 五、Layer 2 主选题重写模板（强制）

### v2.6.1 标准三段式结构（已验证）

```
【主选题】
[全球性钩子]: "[全球共性现象]——[中国为何不同]"
[控制性理念]: 锚点 + 中国语境的双重命题

【R · 场景爆破】
- 全球层数据炸弹（95% / 80% / $9B）
- 中国层数据炸弹（47.5% / 72% / 2.5T / 1/10 Token）

【I · 照亮盲区——三段式】
第一层：全球 95% 共性问题 → 失败的不是 AI，是部署
第二层：美国解法 → Palantir FDE → 微软 Frontier Company
第三段（v2.6.1 必含）→ 中国解法三路径：
  - 路径一：云厂 MaaS（字节火山引擎/阿里百炼）
  - 路径二：咨询公司 H 型架构（传世智慧/薄云咨询/360）
  - 路径三：制造业自有智能体（美的/三一/中国电信）

【V · 验证处境】
- 全球：微软股价 -21% / 埃森哲 -18%
- 中国：3800亿三年承诺 / 47.5% 渗透 / 8/16 灯塔 / 千问 Token 1/10

【E · 具身化】
- 核心隐喻 #1：AI 是引擎，需要会开车的人（全球共性）
- 核心隐喻 #2（v2.6.1 必含）：AI 是水电，但接电是工程（中国语境）
- 反常识类比："[大公司 25 亿] vs [一人公司 20 块]"

【T · 转化行动】
- 信号 1：全球共性"人是护城河"
- 信号 2：中国特色"千问 1/10 Token 革命"
```

## 八、反模式

### ❌ 反模式 1：把"中国视角"当单独章节追加
正确做法：将中国视角作为 Layer 2 的"第三段"（三段式结构）

### ❌ 反模式 2：只查"中国 AI 厂商"不查"中国政策"
正确做法：必查工信部/发改委/国务院政策

### ❌ 反模式 3：中美对比陷入二元论
正确做法："路径 A vs 路径 B vs 路径 C"（用 6 维差异表呈现）

### ❌ 反模式 4：忽略估值/股价反差数据
正确做法：同时引用"调用量反超"和"估值落差"两类数据（保留张力）

### ❌ 反模式 5：中文搜索调用少于 5 组
正确做法：默认 8 组（按第四节顺序执行）
