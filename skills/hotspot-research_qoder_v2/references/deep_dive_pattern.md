# 横纵深度专题模板（精简版）

> **用途：** 周报 Step 8 对 #1 事件执行横纵分析。也可手动触发。
> **来源：** 参考 khazix hv-analysis 横纵分析法，适配 SOUL 四视角。
> **篇幅：** 1000-1500 字（精简版，非完整万字研究）
> **超时保护：** 500s 硬截止，超时 → 降级为标题+3条要点

---

## #1 事件选择逻辑

```
优先：P0 标签 + 本周出现 ≥ 3 天（从日报「本周线索」统计）
降级：无 P0 时选最高 P1 + 重复 ≥ 2 天
跳过：全周无 reach ≥ 2 的事件 → 标注"本周无可聚焦事件"
```

---

## 分析模板

### 纵轴：怎么走到今天的（300-500字）

```
1. 起源（1-2句）：这件事从哪冒出来的？最初形态是什么？
2. 关键节点（3-5个）：按时间顺序列出里程碑，每个节点讲清楚"为什么是这一步"
3. 阶段划分（1段）：把整个历程分为2-3个阶段，每个阶段的核心矛盾是什么
```

### 横轴：此时此刻它在哪（300-500字）

```
1. 同类对比（2-3个）：与最相似的竞品/事件的差异矩阵
2. 格局位置：在赛道版图中占什么位置？填补空白还是正面竞争？
3. 用户/行业反应：真实口碑、被提及最多的优点和槽点
```

### 交汇洞察（300-500字）

```
1. 历史如何塑造今天的位置（1段）
2. 优势/劣势的历史根源（各1段）
3. 未来推演：三个剧本——最可能/最危险/最乐观
```

---

## SOUL 四视角强制注入

每个视角 1-2 句，嵌入交汇洞察末尾：

| 视角 | 问题 |
|------|------|
| **叙事学** | 这个故事该怎么讲给受众？用什么故事结构？ |
| **心理学** | 触动受众哪个焦虑/防御机制/认知扭曲？ |
| **人类学** | 受众处于转型哪个阶段（分离/阈限/融入）？ |
| **产品策略** | 可转化为什么内容选题？什么平台？什么形式？ |

---

## 执行流程

```
1. WebSearch 深度搜索 1 次（使用关键词组合，获取 top 15 结果）
2. WebFetch / Jina Reader 精读 2 篇原文（如有）
3. 按模板撰写：纵轴 → 横轴 → 交汇洞察 → SOUL 四视角
4. 嵌入周报「🔥 本周深度专题」板块
```

---

## 降级策略

```
到 500s 时若未完成：
  ├─ 已写完纵轴+横轴 → 交汇洞察精简为 3 条要点
  ├─ 只写完纵轴 → 标题 + 3 条要点 + 标注"深度分析超时，下周可补"
  └─ 未开始 → 标注"深度分析超时跳过"，不影响周报主体
```
