## 案例 1：报道中概念的学术溯源校准（2026-06-29）

**陷阱类型**：事实校准（"学术概念 vs 报道者自创"误判）

**原始陷阱**：
> 日报中写「她女儿 Sofia 创造了'认知投降'概念」——但实际「认知投降」是 Wharton Shaw & Nave 2026 年 1 月论文《Thinking — Fast, Slow, and Artificial》中的正式学术术语。Sofia 在文章中只是引用了这项研究。

**为什么危险**：
- 错误归属会扭曲对「母女对话」性质的理解——把它当成"女儿原创批判"，而非"女儿引用学术研究支持自己的判断"
- 削弱对 Wharton 研究者作为「认知框架权威」的定位
- 在内容中误传概念创造者会让 SOUL 受众对"什么是真学术、什么是评论引用"产生混乱

**修正动作**：
1. 概念溯源标准动作：每出现一个"X 创造/提出/发现 Y 概念"的表述，立即用 `WebSearch` 反向溯源 `Y 概念 + 原始论文/作者`
2. 引用学术概念时必须标注「(Author1, Author2, Year) + 论文标题」三要素
3. 在内容钩子中**保留引用方**而非**创造方**——例如：「Sofia 在达特茅斯论文中引用了 Wharton 的'认知投降'研究」比「Sofia 创造了认知投降这个词」准确

**验证信号**：
- 至少 3 个独立来源（原始论文 / 媒体报道 / 研究者访谈）确认同一学术源头
- 论文作者姓名、研究时间、机构、刊物均可溯源

## 案例 2：跨源数据冲突的处理（2026-06-29）

**陷阱类型**：事实校准（"不同口径混用"陷阱——SKILL.md 校准清单第 2 项"不同口径混用"的具体案例）

**原始数据冲突**：
| 来源 | 数据 |
|------|------|
| Forbes 报道 | 信心提升 10% |
| The Next Web 报道 | 信心提升 11.7% |
| Wharton Executive Education | 信心提升 10% |

**真实情况**：
- 10% 来自 3 个实验中的某几个特定条件
- 11.7% 是某个实验条件下的具体测量
- **两个数据都对，但来自不同实验条件**——不是"哪个对"的问题，是"哪个实验条件下哪个数据"

**修正动作**：
1. 出现"X% vs Y%"冲突时**不要立即选一个**，先用 LLM Context 读研究者访谈/播客原文确认两个数据各自的实验条件
2. 报告中并列两个数据 + 各自条件：「Forbes 报道 10%（早期实验），The Next Web 引用 11.7%（后续实验）」，并附上研究者的明确表述作为最高权威
3. **绝不要在内容中只用一个数据并标注唯一性**——保留两个数据展示了方法论的严谨性

**验证信号**：
- 跨源数据冲突时，研究者本人（Shaw / Nave）的访谈/播客/邮件答复是最高权威
- 论文 PDF（如果能获取）附录通常有完整的实验条件表

## 案例 3：发散引擎的"GPS 类比链"验证（2026-06-29）

**陷阱类型**：方法论验证（"发散模式是否真的有效"——SKILL.md Step 2B "跨领域类比迁移"的具体案例）

**实际验证**：
- 本次深挖执行了 "伦敦出租车司机海马体增大 → GPS 依赖者海马体萎缩 → AI 依赖者前额叶？"三步类比链
- **结果**：成为本次延展选题 D-3 独立抖音/小红书选题，内容生产价值高

**方法论价值**：
- 三步类比链是发散引擎的「高 ROI」模式：起点是熟悉的现象（GPS 类比已被大众接受），终点是不熟悉但需要解释的现象（AI 认知投降）
- 每步类比必须满足「神经科学/认知科学文献支撑」+「不强行类比」

**修正动作**：
1. 发散引擎寻找类比时优先用「神经科学 + 已发生的历史技术」为支点——比纯哲学类比更有说服力
2. 三步类比链的「第三步」（类比目标）必须有"科学假设"而非"修辞比喻"——如"AI 依赖者前额叶？"带问号，表示这是 hypothesis 而非 claim
3. 如果第三步找不到科学文献支撑，类比链降级为两步，明确标注"未来研究方向"

**相关参考**：SKILL.md Step 2B "跨领域类比迁移"行已有此发散模式作为示例，但本案例提供了一次实际验证记录。

## 案例 4：「认知萎缩 vs 认知止赎」新概念发现（2026-06-29）

**新知识（不是 skill 更新目标，但需要记住）**：

| 概念 | 心理学/神经科学含义 | SOUL 受众对应 |
|------|------------------|-------------|
| **认知萎缩（Cognitive Atrophy）** | 已有能力因不用而退化——**可逆** | Marcus（30-38）：长期用 AI 替代思考导致的"变钝"——可以通过刻意练习恢复 |
| **认知止赎（Cognitive Foreclosure）** | 能力从未被建立——**可能不可逆** | Z（18-22）：从青少年起就用 AI 替代思考，思考能力从未"建造"——"你不能让一块从未存在过的肌肉萎缩" |

**来源**：Timothy Cook M.Ed., Psychology Today "The Algorithmic Mind" 专栏，2026-03-22《Adults Lose Skills to AI. Children Never Build Them.》

**内容生产价值**：
- 提供了 SOUL 受众分层的**心理学硬支撑**——不只是"年轻人 vs 老年人"的经验观察，是"成人可逆 vs 青少年可能不可逆"的机制差异
- 可以作为多个新选题的"金句"：「你不能让一块从未存在过的肌肉萎缩」
- 与 SOUL 控制性理念完美对齐——"真实稳定的自我"对成人是"维护"，对孩子是"建造"

**提醒**：本知识应通过 `references/key_persons.md` 追加 Timothy Cook 到"心理学追踪人物清单"，或更新 `references/keywords.md` 补充"cognitive atrophy / cognitive foreclosure"两个术语。
