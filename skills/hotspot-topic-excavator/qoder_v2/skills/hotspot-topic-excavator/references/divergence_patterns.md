## 模式 1：GPS 类比链（跨领域类比迁移）

### 触发条件
- 锚点涉及「认知功能外包」「技能退化」「工具依赖」等概念
- 受众需要「这不只是 AI 的问题」层面的证据
- 需要将陌生概念（AI认知投降）连接到熟悉现象（GPS导航）

### 搜索策略
三阶段阶梯搜索：

```
阶段 1：建立类比基础
  WebSearch: "GPS navigation spatial reasoning atrophy hippocampus London taxi driver"
  → 获取科学背书（伦敦出租司机海马体研究）和非技术类比文章

阶段 2：连接到 AI
  WebSearch: "AI cognitive offloading GPS analogy hippocampus brain atrophy"
  → 找到明确将 GPS 与 AI 关联的文章（如 saydo.design, Sciety "GPS for Thinking"）

阶段 3：深化类比链
  WebSearch: "cognitive disuse atrophy GPS compass metaphor education AI"
  → 获取「方向性类比」：GPS 命令式导航 vs 指南针式定向
```

### 推荐信源组合
| 信源 | 角色 | 典型产出 |
|------|------|---------|
| Nature Communications (2017) | 原始科学数据 | GPS使用降低海马体活动 |
| saydo.design / Medium | 类比桥梁文章 | "The GPS Test: AI cognitive atrophy" |
| Sciety (2026) | 教育视角 | "AI as GPS for thinking" → compass alternative |
| arXiv 2502.12447 | 文献综述 | GPS→搜索引擎→AI 的历史脉络 |

### 类比链路模板
```
具体现象（出租车司机海马体增大）
    ↓
反向现象（GPS依赖者海马体萎缩）
    ↓
规律提炼（「外包什么就失去什么」是神经系统基本原则）
    ↓
当代映射（AI 是认知领域的 GPS——系统性地外包思考）
    ↓
出路对照（GPS 的 compass 替代 → AI 的 Scaffolded Friction 替代）
```

### 产出样例（2026-06-03 认知投降深挖）
- 素材类型：案例故事（CASE-5）+ 对立张力（TEN-1）
- 数据点：伦敦出租车司机研究 + Nature Communications + Sciety "GPS for Thinking" (2026-05-26)
- 用途：B站长视频论证支柱 / 小红书「为什么这不是AI独有的问题」对比图

## 模式 2：LLM Context 作为 P1 原文提取首选（信息完整度优化）

### 触发条件
- 锚点核心信源是 Substack / Medium / 博客平台
- WebFetch 不可用或未安装
- 需要 85%+ 信息完整度以达到深度分析标准

### 策略
```
并行启动（不要等待 WebFetch 失败后才用 LLM Context）：
  WebSearch(query="[作者名] [文章标题] [核心概念]")
  + 同时（如有）WebFetch

LLM Context 参数调优：
  count=15（足够覆盖多段核心内容）
  maximum_number_of_urls=5（聚焦核心信源）
  → 返回 grounding.generic[].snippets 含原文段落、金句、数据
```

### 完整度阶梯（实测数据）
| 方法 | 典型完整度 | 适用场景 |
|------|-----------|---------|
| LLM Context (单工具) | 85-95% | Substack / Medium 长文 |
| LLM Context + 2组 web_search 交叉 | **95%** | 需要多源验证的深度分析 |
| WebFetch (可用时) | 95-100% | 干净 Markdown 全文 |
| 仅 web_search snippets | 50-60% | 快速扫描 / 低优先级主题 |

## 模式 3：反方观点的系统性纳入（对立张力增强）

### 触发条件
- 锚点概念有明确的学术/行业反方
- 内容需要「不只是非黑即白」的智识张力
- 需要避免受众产生「AI=坏」的误解

### 搜索策略
```
阶段 1：识别反方人物
  从核心信源中提取被引用或批评的人物（如 Mollick→引用 Andy Clark）

阶段 2：获取反方原文
  WebSearch / web_search: "[反方人物] [关联概念]"
  如：Andy Clark "extended mind" AI augmentation

阶段 3：建立正方-反方-综合的三层结构
  正方（Mollick/Shaw）→ 反方（Clark）→ 综合（Mollick 自己的矛盾：拥护AI但警告）
```

## 模式 5：V1+V2 对比报告的自动生成

### 触发条件
- V1 材料库（topic_materials_*.md）已存在
- 本次 V2 深挖产出完成
- 需要向用户展示「这次深挖比内部探查多了什么」

### 对比维度

| 维度 | V1（内部探查） | V2（联网深挖） | 增量 |
|------|:--:|:--:|------|
| 信源数量 | N1 | N2 | +ΔN |
| 联网信源 | 0 | N_web | 100% 新增 |
| 信息完整度 | C1% | C2% | +ΔC |
| 图片素材 | 0 或少量 | 6+3+3 | 完整新增 |
| 反方观点 | 无 | 有/无 | 定性提升 |
| 延伸分析素材 | 少量 | 多角度覆盖 | 分析深度提升 |

## 模式 6：多信号并行搜索（颗粒化多信源话题的高效采集） ★

### 触发条件
- 锚点话题信号高度分散（≥5个独立人物/事件/信源，非2-3个核心信号的对位关系）
- 深挖和发散边界模糊——发散素材本身也是核心素材（如"6州立法运动"既是深度也是广度）
- 时效紧迫（如政策窗口期48h内必须产出）

### 搜索策略
```
单轮并行启动（一个响应内6-7个工具同时触发）：
  WebSearch × 4-5（核心种子分路搜索，一个信号一路）
  + WebSearch × 1（补采最高优先级原文全文）
  + WebSearch × 1-2（发散轴跨领域/历史先例搜索）

→ 全部返回后一次性合成素材（合并去重、分级、分类）
    ↓
如有缺口，发起第二轮补充搜索：
  WebSearch × 1-2（针对第一轮发现的核心原文URL）
  + WebSearch × 1-2（补采新发现的关键词）
```

### 参数调优速查
| 搜索类型 | count | freshness | 用途 |
|---------|:--:|-----------|------|
| 核心种子深度搜 | 10 | pw | 确保时效+覆盖面 |
| 核心原文补采 | 5（LLM Context） | 默认 | 全文核心段落+金句提取 |
| 发散历史先例 | 10 | 不限 | 类比链+跨领域素材 |
| 发散政策/法律 | 10 | pw | 最新立法+多州交叉 |

### 适用信号类型速查
| 信号类型 | 搜索策略 | 示例 |
|---------|---------|------|
| 人物会面/密谈 | web_search + LLM_Context | Altman×Sanders密谈 → AP/WaPo全文 |
| 政策声明 | web_search(pw) + 官方来源 | Trump空军一号 → Politico+Reuters double-sourced |
| 地方争议 | web_search(pw) × 2-3信源角度 | 密歇根数据中心 → 本地媒体+进步媒体+环境媒体 |
| 全国性立法运动 | web_search(pw) × 多州名并行 | "自己付电费" → NY/TN/NC/PA/ME 5州交叉验证 |
| 历史先例/类比 | web_search(不限时效) | Alaska Permanent Fund → 1976 founding story |
| 财务/估值数据 | web_search + 财经媒体 | OpenAI $44B亏损 → Fortune/WSJ cross-referenced |

## 模式 7：全WebSearch降级模式（Brave + WebFetch 同时不可用）★ 2026-06-13 新增

### 触发条件
- WebSearch：SUBSCRIPTION_TOKEN_INVALID 或 MCP server unreachable
- WebFetch：AS30058 IP 信誉阻止
- **两者同时发生** → 进入全 WebSearch 降级模式

### 核心策略
不逐个 URL 抓取 → 用 WebSearch 的多角度搜索覆盖所有种子信号。WebSearch 的 `results[].content` 返回的是**文章核心段落**而非短 snippet，在多数情况下足以支撑深度分析。

### 搜索策略（两轮覆盖）
```
第一轮：核心信号深度覆盖（4-6 组并行）
  WebSearch ×1: 锚点人物+核心概念 — topic=news, days=7, n=15
  WebSearch ×1: 锚点概念+学术/政策角度 — search-depth=advanced, n=15
  WebSearch ×1: 关联信号（如中国侧）— topic=news, days=7, n=10
  WebSearch ×1: 对立信号/竞争事件 — topic=news, days=7, n=10  
  （如有更多信号，追加 1-2 组）

→ 全部返回后检查覆盖面
    ↓ 如有明显缺口
第二轮：缺口补采 + 发散轴（2-4 组并行）
  WebSearch ×1: 第一轮发现的关键原文 URL 相关词
  WebSearch ×1: 发散·历史先例/跨域类比 — search-depth=advanced, days=30
  WebSearch ×1: 发散·反方观点/对立叙事 — topic=news, days=14
  WebSearch ×1: 发散·政策/法律后果 — topic=news, days=14
```

### 可达到的完整度
| 信号类型 | 典型完整度 | 局限 |
|---------|:--:|------|
| 核心人物政策/博文 | 85-90% | 缺原文全文，但有核心段落和金句 |
| 权威媒体报道 | 80-85% | 付费墙内文（Bloomberg/WSJ）仅标题级 |
| 学术论文 | 60-70% | 仅摘要级，无全文方法和数据 |
| 社区讨论 | 70-80% | Reddit/X 可获取但噪声高 |
| 发散·历史类比 | 75-85% | 跨域搜索覆盖良好 |
| **综合** | **85-93%** | — |

### 实测效果（2026-06-13 Amodei全球共振深挖）
- **WebSearch 组数**：8 组（第一轮 4 组核心 + 第二轮 4 组补采/发散）
- **信源数量**：15+（Business Insider, AP, Gizmodo, Politico, TechCrunch, NYT, Reuters, Guardian, WaPo, Forbes, Mashable, The Atlantic, CNBC, WebSearch（中文） 等）
- **信息完整度**：93%
- **关键成功因素**：Amodei 政策文被多家媒体全文引用核心段落 → WebSearch 返回的 snippets 包含了 "intrinsic property of the technology" 等关键原话
- **缺失项**：Amodei 原文 PDF 全文、Bloomberg 付费墙内文、Sanders 法案原文

### 与其他模式的组合
- 模式 6（多信号并行搜索）→ 本模式的分组逻辑即模式 6 的 WebSearch 适配版
- 模式 3（反方观点纳入）→ 第二轮发散搜索中实现
- 模式 1（GPS 类比链）→ 第二轮发散·历史先例搜索中实现
- 模式 4（多平台大纲差异化）→ 不受影响，素材采集完成后正常执行
- 模式 5（V1+V2 对比）→ 报告末尾新增「与日报 V1 的比较分析」章节

## 模式 8：罗生门叙事结构（矛盾叙事并置）★ 2026-07-05 新增

### 触发条件
- 同一话题在同一时间窗口内出现 **≥3 个互不兼容的叙事**（如：AI在消灭岗位 vs AI还不够好替代不了人 vs AI裁员是叙事多于事实）
- 不同信源类型（企业行为 / 媒体调查 / 政府数据）对同一现象给出矛盾结论
- 话题本身具有「罗生门」属性——每个叙事单独看都成立，并置才揭示完整真相

### 核心策略

**三步构建罗生门结构**：

```
步骤 1：识别三路矛盾信号
  信号 A（企业行为层）：如 Microsoft 裁员 + AI 基建 → "AI在消灭岗位"
  信号 B（媒体调查层）：如 CNBC 裁员反转 → "AI还不够好"
  信号 C（政府数据层）：如加州追踪器 → "AI裁员叙事多于事实"
  → 三个信号必须来自不同信源类型（企业/媒体/政府），才能形成真正的罗生门

步骤 2：验证每条叙事的「局部真值」
  → 每条叙事单独看是否成立？如果成立 → 罗生门成立
  → 如果某条叙事本身有误 → 那不是罗生门，是 misinformation

步骤 3：并置揭示「完整真相」
  → 三条叙事同时成立的原因：它们描述的是同一现象的**不同层面**
  → 结论不在任何一条叙事中——在三条叙事的**张力关系**中
```

### 搜索策略
```
并行启动三路搜索（每条叙事独立深挖）：
  信号 A 搜索：核心事件 + 财务数据 + 公司声明
  信号 B 搜索：反转案例 + 调查报道 + 当事人原话
  信号 C 搜索：政府数据 + 政策工具 + 官方结论

→ 每条信号独立验证后 → 并置对比 → 提炼「张力关系」
```

### 罗生门 vs 传统对立张力

| 维度 | 传统对立张力（模式 3） | 罗生门叙事结构 |
|------|---------------------|---------------|
| 信源数量 | 2（正方 vs 反方） | ≥3（不同信源类型） |
| 关系 | 对立（谁对谁错） | 并置（都对，但层面不同） |
| 结论 | 综合/折中 | 张力本身就是结论 |
| 受众效果 | 「原来不是非黑即白」 | 「每条都成立，但合在一起才是真相」 |
| 适用话题 | 有明确争议点的话题 | 多源矛盾共存的话题 |

### 产出结构模板
```
┌─────────────────────────────────────┐
│ 牌一：[信号A标题]                     │
│   核心数据 + 隐含结论                  │
├─────────────────────────────────────┤
│ 牌二：[信号B标题]                     │
│   核心数据 + 隐含结论                  │
├─────────────────────────────────────┤
│ 牌三：[信号C标题]                     │
│   核心数据 + 隐含结论                  │
├─────────────────────────────────────┤
│ 罗生门解读：三条叙事同时成立的原因       │
│   → 描述的是同一现象的不同层面          │
│   → 完整真相在张力关系中               │
└─────────────────────────────────────┘
```

### 受众共鸣机制
- **认知震惊**：「同一件事怎么有三个完全不同的"真相"？」
- **智识满足**：「原来每条都是对的——只是层面不同」
- **行动清晰**：「理解了完整图景后，我知道该怎么做了」

### 产出样例（2026-07-05 AI裁员罗生门深挖）

| 牌 | 信号 | 核心数据 | 隐含结论 |
|----|------|---------|---------|
| 牌一 | 微软第三轮裁员 + $190B AI基建 | 裁20,500人（销售/咨询/Xbox），AI基建$100B+ | "AI在消灭岗位" |
| 牌二 | CNBC裁员反转调查 | Ford 350人回归 / CBA撤销裁员 / IBM入门招聘翻三倍 | "AI还不够好，替代不了人" |
| 牌三 | 加州AI失业追踪器 | 160+企业裁员，0家归因AI；全州未检测到激增 | "AI裁员叙事多于事实" |

**罗生门解读**：三条叙事同时成立——因为它们描述的是同一现象的**不同层面**。微软描述的是「投资方向转移」（裁旧投新），CNBC描述的是「替代执行失败」（技术不够好），加州描述的是「企业归因行为」（嘴上说AI，报告里不写）。完整真相：AI裁员是一个由企业叙事、技术局限和政策焦虑共同编织的复合现象。

### 适用话题识别
- ✅ 多源数据对同一现象给出矛盾结论
- ✅ 企业行为 vs 媒体调查 vs 政府数据的三角矛盾
- ✅ 「AI就业」「AI替代」等天然多面性话题
- ❌ 单一信源或两方对立的简单争议（用模式 3 即可）
