# 罗生门型话题·对立张力分析模式

> **来源**：2026-07-05「AI是平权还是加剧不平等的罗生门」深挖实战
> **核心特征**：话题本身没有单一"正确答案"——双方都有真实证据、真实案例、真实逻辑。内容价值不在"站队"，在"呈现张力并让受众自己判断"。
> **与 divergence_patterns.md 的关系**：divergence_patterns 覆盖发散方向（关联/对立/跨域等），本文件覆盖**当话题本身就是对立叙事时的素材组织方式**。

---

## 一、识别：什么话题是"罗生门型"？

| 特征 | 检查方法 |
|------|---------|
| **双方都有真实证据** | 不是"一方有数据一方只有观点"——双方都有可溯源的硬核事实 |
| **双方都有真实案例** | 不是"一方有故事一方只有抽象"——双方都有具体的时间/人物/结果 |
| **没有明确的"正确答案"** | 学术/政策界仍在争论，不是"科普纠正误解"型话题 |
| **受众本身就在两难中** | 话题触动的不是"他们不知道"——是"他们知道两边都有道理但不知道该信哪边" |

**本次案例**：AI是平权还是加剧不平等？
- 正方证据：加纳WhatsApp数学课、巴西亚马逊远程教育、印度$15B AI枢纽
- 反方证据：90%算力集中中美、Tigrinya翻译灾难、Token定价制造认知阶级
- 受众处境：转型者Marcus既用AI提升效率又担心AI替代自己——他在两边都能看到自己

---

## 二、对立张力表的构建规则

### 核心原则：**每个张力维度必须同时有正方和反方的真实证据**

```markdown
| 张力维度 | 正方（AI=平权工具） | 反方（AI=不平等放大器） |
|---------|---------------------|------------------------|
| [维度名] | [真实案例/数据/引述 + 来源] | [真实案例/数据/引述 + 来源] |
```

### 反模式（不要做）

| ❌ 反模式 | ✅ 正确做法 |
|----------|-----------|
| 正方用具体案例，反方用抽象概括 | 双方都用同等粒度的具体证据 |
| 正方有数据，反方只有"但也有风险" | 反方必须有对等的数据/案例 |
| 把反方证据放在"争议"小节，正方放在"事实"小节 | 同表同权重，不暗示哪方是"正确答案" |
| 张力维度只有3-4个 | 罗生门型话题至少需要6-8个维度才能充分呈现复杂性 |

### 维度设计指南

选择能**独立验证**的维度——每个维度应该是可独立论证的子命题，而非同一论证的不同说法。

**本次案例的8个维度**：教育、医疗、金融服务、语言、就业、创业、治理参与、能源环境——每个维度都可以独立写一篇短文。

## 三、SOUL框架的连接方式

罗生门型话题天然适配SOUL的核心张力：

| SOUL概念 | 在罗生门话题中的应用 |
|----------|---------------------|
| **控制性理念** | "真实稳定的自我是唯一不可被替代的资产"——当外部世界本身就是矛盾的，内在一致性成为唯一的锚 |
| **correlate vs understand** | AI能关联双方的证据，但不能"理解"为什么两方同时为真——理解这个悖论需要人的判断力 |
| **有限性智慧** | 承认"我不知道哪方是对的"本身就是有限性智慧——比假装有答案更有力量 |
| **通过仪式** | 受众从"AI是好的/坏的"（分离期·二元思维）→"AI同时是好的和坏的"（阈限期·悖论容纳）→"我在矛盾中找到自己的位置"（融入期·主体性建构） |

## 四、报告结构建议

罗生门型话题的报告结构应与普通话题有所区分：

### 调整点

| 模块 | 普通话题 | 罗生门型话题 |
|------|---------|-------------|
| **执行摘要** | "核心叙事线：X导致了Y" | "核心叙事线：X和Y同时为真——这不是矛盾，这是复杂性" |
| **对立张力** | 可选，通常3-5个维度 | **核心模块**，至少6-8个维度，每条都有对等证据 |
| **RIVET的R（Rupture）** | 用一个反常识打破平衡 | 用"两边都对"打破"必须选一边"的常识——"联合国40个科学家说：我们也不知道净效应是什么" |
| **RIVET的T（Transform）** | 给出行动建议 | 给出**在矛盾中找到自己位置**的行动建议——不是"选哪边"，是"你在这个结构里可以做什么" |
| **再创作选题** | 可以是单边深挖 | 至少1个选题保持"罗生门"结构，至少1个选题做单边深挖（满足不同受众需求） |

### 关键金句公式

> 「[话题]不是[简单结论]——是[双方证据同时为真的悖论]。这不是让你选边站——是让你在矛盾中找到自己的位置。」
