## Layer 2 ｜ 文章/视频大纲 + 素材填充

### RIVET 结构

**R · 场景爆破（Rupture）**
- 钩子：从今天开始，你和 AI 聊天的时候，它必须告诉你："我是一个 AI 系统。"这不是 ChatGPT 的善意提醒，而是欧盟 AI 法第 50 条的强制义务。
- 反常识：你可能认为这只是欧盟对 AI 行业的"又一条规管"，但它真正影响的是全球每一个面向欧洲用户交付内容的公司和平台——Meta、Google、Microsoft 统统签了 Code，包括那些你认为"拒绝监管"的科技巨头。
- 核心冲突：**"自愿遵守 Code"vs"强制法律义务"**——EC 说 Code 是自愿的，但第 50 条的义务是强制的。你要么选 Code 提供的简化路径，要么单独证明你的替代方案"同样充分"。

**I · 照亮盲区（Illuminate）**
- 核心论证：EU AI 法透明度义务不是简单的"贴标签"运动，而是**全球首个 AI 立法的执行期起点**：
  - **从"禁止什么"到"透明什么"**：之前的高风险 AI 禁令（如生物识别、社会评分）只是第一部分，第二部分是通用 AI 的透明度要求（让所有人知道自己在和谁/什么交互）
  - **Provider vs Deployer 的责任分工**：提供者为输出添加机器可读标记；部署者向用户披露（特别是 Deepfakes 和公共文本）
  - **罚款威慑力**：€750 万 or 1% global turnover → 对于大型跨国公司，这个数字可能是几十亿欧
- 盲区 1："Meta 拒绝加入 Code"的传言不准确——Meta 实际上**签署了 Section 1**（作为 Generative AI 模型的提供者）。它的问题在于：作为全球最大的社交平台之一，它的数百万个 AI 生成内容部署者角色（如广告推荐算法生成的帖子）可能需要额外承担 Section 2 责任，这可能超出其当前承诺。
- 盲区 2：EC 设计了专门的设计图标体系（EU Icons）来标准化 labeling 过程——这意味着不是每个公司自己设计 label，而是有统一的视觉识别系统。

**V · 验证处境（Validate）**
- 数据支撑：
  - ~190 家组织已签署 Code（Section 1:82 家 / Section 2:152 家）
  - 其中约一半为中小企业（highlighting small and recent companies 的动态 nature）
  - IT/Telco/Education/Retail 等行业企业均参与其中
  - 从 2025.09 Consultation → 2026.06 Final Code → 2026.08.02 Effective = 仅用 11 个月完成从设计到生效
  - 2026.09 启动两个 Signatory Taskforces 分享最佳实践
  - 罚款上限：€750 万 or 1% global turnover（取高者）
- 验证路径：EC Guidelines → Code of Practice → Signatories List → Enforcement Framework

**E · 具身化（Embody）**
- 核心隐喻：**"AI 产品的身份证时代"**
  - 想象一下：你进入一个房间，所有新来的"人"都必须出示自己的身份证，上面写着"我是人类/我是 AI"。如果某个"人"拿不出证件，你就有权怀疑他的身份。
  - 对 EU AI 法来说，这就是第 50 条的逻辑：AI 不是黑盒，它有义务在交互开始时告知用户"我是个 AI 系统"。如果它不这么做，它就违法了。
- 反面隐喻："**深度伪造的身份证造假**"：如果一个 Deepfake 视频没有标注机器可读标记和可见标识，那它不仅是非法的，还可能被推定为恶意欺诈——因为法规假设"合法的 Deepfake 都会主动标注"。

**T · 转化行动（Transform）**
- 行动建议（面向超级个体/AI从业者）：
  1. **检查你的业务是否涉及"欧盟用户"**：如果你的产品/服务/内容有欧洲受众（哪怕只有少量），你就受第 50 条管辖
  2. **如果你是 Generative AI 模型提供者**：尽快签署 Code 的 Section 1 → 获得统一合规路径和法律确定性
  3. **如果你部署 AI 生成内容**（如广告平台、社交媒体、内容托管）：评估是否需要签署 Section 2 → 使用 EC Icons 标准化 labeling
  4. **如果你是 Deepfake 创作者**（影视特效、虚拟主播等）：你的内容**必须**有可见标识 + 机器可读标记 → 否则面临最高€750 万罚款
  5. **关注 9 月启动的任务组**：Signatory Taskforces 会分享最佳实践 → 提前准备你的合规方案以便参与讨论
