#### 文件 B：TC260《智能体部署使用安全指引》（7/1 全国网安标委）
**五阶段安全管控框架**：
1. **评估阶段**：安全风险评估、供应商资质审查、数据安全评估
2. **准备阶段**：运行环境隔离、权限最小化、网络边界控制
3. **部署阶段**：身份认证、接口安全、日志审计、异常监控
4. **使用阶段**：人机交互边界、高风险操作人工确认、工具调用沙箱
5. **停用阶段**：数据清除、权限回收、审计归档

**关键技术要求**（直接对标 JADEPUFFER 防御）：
- 高风险操作必须设置人工确认机制（对应 4-6 个人类决策点的监管要求）
- 智能体账号遵循最小必要权限原则（对应数据库 root 权限滥用问题）
- 运行环境隔离，关闭非必要互联网访问端口（对应 Langflow 公网暴露问题）
- 工具调用沙箱化，防止越权执行（对应 600+ payload 自主发射问题）

#### 文件 C：GB/Z 185-2026《人工智能 智能体互联》系列国家标准（7/2）
**7 项标准构成**：总体架构、身份码、身份鉴别、消息协议、服务发现、协同决策、安全要求

**核心安全设计**：
- 可信身份基础：智能体身份码分层标识体系，为跨系统协作提供安全保障
- 四大身份机制：身份码、身份账户、身份凭证、身份鉴别
- 核心原则：连得上 + 信得过 + 管得住 + 可追溯

**参与单位**：中国电子技术标准化研究院牵头，华为、清华、360 等 70+ 产学研单位共同研制

#### 文件 D：《智能助手类智能体安全分级规范与建设指南》（6/10）
**L1-L5 五级安全分级体系**：
| 级别 | 名称 | 自主程度 | 适用场景 |
|------|------|----------|----------|
| L1 | 基础级 | 纯问答，无工具调用 | 客服、咨询 |
| L2 | 工具级 | 可调用只读工具 | 信息查询、数据分析 |
| L3 | 执行级 | 可调用执行类工具，需用户确认 | 邮件发送、文件操作 |
| L4 | 决策级 | 有限自主决策，关键节点人工审核 | 业务流程自动化 |
| L5 | 自主级 | 高度自主，全流程可追溯、可中断 | 特定专业领域 |

**JADEPUFFER 对照评级**：按其"高度自主执行 + 仅 4-6 个决策点确认"的特征，属于 L4-L5 之间，已触及当前监管框架的最高风险等级边界。

### 3. 工信部 AI Agent "六要六不要"（3/11）
**六要**：
1. 要使用官方或可信渠道发布的版本
2. 要及时更新到最新安全版本
3. 要设置独立运行环境与权限隔离
4. 要启用操作日志与行为审计
5. 要定期开展安全评估与渗透测试
6. 要制定应急响应预案

**六不要**：
1. 不要使用来源不明的破解版或修改版
2. 不要将智能体直接暴露于公网无防护
3. 不要授予超出必要范围的系统权限
4. 不要在智能体环境中存储明文敏感凭证
5. 不要轻信智能体生成的执行结果直接投产
6. 不要关闭安全监控与告警机制
