## 📖 Quick Start：3 步今晚开始（独立衍生文件）

### 1 分钟理解版

> **复利工程 = 让 AI 记住你犯过的每一个错。**
> **不是写得更多，而是知道得更多。**

### 立即行动（3 步）

#### 第 1 步：选项目（5 分钟）
- 打开你的 git 仓库
- 找到**最小的一个**——一个长跑了一段时间的项目
- 不要选你"最想要成功的"——选你**最有感觉**的

#### 第 2 步：装工具（10 分钟）
- 选项 A：装 [Claude Code](https://docs.claude.com/en/docs/claude-code) 官方 CLI
- 选项 B：装 [Cursor](https://www.cursor.com/) 编辑器
- 选项 C（进阶）：装 Every 复利工程 plugin
  ```bash
  claude /plugin marketplace add https://github.com/EveryInc/every-marketplace
  claude /plugin install compound-engineering
  ```

#### 第 3 步：写第一条复利（10 分钟）
- 在项目根目录建 `CLAUDE.md` 文件
- 写第一行（这是 SOUL「诊断前置，处方在后」的具身化）：
  ```markdown
  # Project Notes (append-only)
  
  ## 2026-07-05: Initial State
  - Prefer functional programming style.
  - Don't use heavy frameworks unless I ask.
  - When implementation has more than 3 trade-offs, pause and ask.
  ```

#### 下周工作流（每个工作日）
1. 工作中遇到任何 AI 犯的错（「哦它又这样写了」）
2. **不要只修复**——加一行到 CLAUDE.md：
   ```
   ## 2026-07-06: Don't use snake_case in this project; we use camelCase.
   ```
3. 把"如何修复这个 bug"写进 `docs/solutions/YYYY-MM-DD-bug-name.md`
4. 下次 AI 会自动读这份文档——会避开同样的坑

### 30 天后预期
- **CLAUDE.md** 从 1 行变 50 行——AI 现在比 GPT-6 还懂你的项目
- **`docs/solutions/`** 从空文件夹变成 8-10 篇解决方案——新成员上手时间从 1 周变 1 天
- **你自己**——也是第一个感觉到复利的人：**你每写 1 行，AI 下次就少犯 1 次错**

> 这就是复利。
> 不是你写更多，是 AI 记得更多。
