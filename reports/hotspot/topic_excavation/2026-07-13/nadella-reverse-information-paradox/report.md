| S3 | **"三重排泄物"模型** — 企业泄露的三类知识：① Prompts（你在做什么）② Corrections（你的行业专业知识）③ Evals（你的质量定义） | 概念 / 分析框架 | P0 |
| S4 | **人力资本 + Token 资本** — 纳德拉将企业 AI 资产拆为两部分：人力资本（员工知识/判断/关系）+ Token 资本（企业自有的 AI 能力） | 概念 / 新术语 | P1 |
| S5 | **"控制权测试"** — 一家公司应能替换掉通用模型而不丢失学习系统中沉淀的经验。这是 AI 时代企业主权的试金石 | 概念 / 可操作标准 | P1 |
| S6 | **五 fronts 解决方案** — Control（evals/memory 归你）、Capability（私有微调环境）、Choice（不依赖单一模型）、Cost（可切换=可择优）、Compound（学习循环内部复利） | 框架 / 行动指南 | P1 |
| S7 | **"信任边界"（Trust Boundary）** — 数据/修正/微调模型在其中积累、未经同意不出界的边界线。合同是纸面边界，专用服务器是物理边界 | 概念 / 架构 | P1 |
| S8 | **全球化第一阶段类比** — "表面上 GDP 数字不错，但产业空心化和就业转移真实发生" → 不要让 AI 重演全球化第一阶段的教训 | 类比 / 历史映射 | P1 |
| S9 | **纳德拉 6/15 前序长文** — 提出"没有人希望所有价值只流向少数模型"、"一个掏空整个行业的 AI 未来不会拥有社会许可" | 前序事件 | P1 |
