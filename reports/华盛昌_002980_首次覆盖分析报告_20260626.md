## 一、投资摘要

### 一句话逻辑

**华盛昌正从"传统仪器仪表制造商"向"AI+高端测试平台型企业"转型，收购伽蓝特切入光通信测试赛道是这一转型的关键一跃——光模块从800G向1.6T/3.2T迭代带来的测试设备量价齐升，叠加国产替代政策红利，构成公司未来3年的核心增长引擎。**

### 核心看点

| 维度 | 要点 |
|------|------|
| **传统业务** | 2025年触底（净利润0.89亿，-35.67%），2026年有望随海外需求恢复+越南产能爬坡企稳回升 |
| **伽蓝特并表** | 2026年5月完成工商变更，全年预计贡献净利润0.38亿+（业绩承诺年均），2027–2028年加速释放 |
| **AI赋能** | DeepSense大模型通过备案、AI眼镜合资公司落地，"AI+测量智能体"战略从概念走向产品 |
| **估值锚** | 当前PE-TTM约166倍反映高预期，但2027年若兑现华创预测的4.87亿净利润，前瞻PE将降至约30倍 |

### 投资建议

首次覆盖给予**「增持」**评级。短期（2026H2）关注伽蓝特整合进展及Q3订单数据验证；中期（2027）若光通信测试业务兑现高增长，估值存在较大重估空间。当前股价已部分price-in乐观预期，建议在110–120元区间分批建仓，止损位设在95元。

## 三、行业分析

### 3.1 仪器仪表行业：万亿级赛道，国产替代加速

**市场规模**：2024年中国仪器仪表行业营业收入突破1.2万亿元（同比+7.8%），2025年预计达1.3万亿元，2030年有望突破2万亿元（CAGR 9.5%）。

**政策驱动**：
- "十四五"规划明确要求2025年国产仪器采购比例提升至50%
- 2024年财政部新增专项资金超50亿元，重点投向质谱仪、基因测序仪等"卡脖子"领域
- 工信部推进仪器仪表全链条突破，叠加首台套保险补偿、政府采购国产化比例等配套政策

**竞争格局**：
- 国际巨头（是德科技、罗德与施瓦茨、泰克、福禄克）主导高端市场
- 国内头部（优利德、普源精电、鼎阳科技、坤恒顺维、华盛昌）在中低端市场形成替代
- 行业集中度提升：前五大企业市场份额超40%，"国际巨头+国内头部+专精特新"三足鼎立

### 3.2 光通信测试设备：AI时代的"卖铲人"

**需求驱动**：
- AI算力集群驱动数据中心光模块从400G→800G→1.6T快速迭代
- 2026年全球光模块出货预计7000万支，其中800G以上超5200万支，1.6T出货量预计1119万支
- 单通道速率提升→测试难度指数级上升→测试设备价值量翻倍
- 采样示波器（核心测试仪器）：2027年市场规模预计突破200亿元

**国产替代空间**：
- 2024年中国光通信测试仪器国产化率仅36.5%，本土企业市场份额约16%
- 是德科技、安立等海外企业占据84%份额
- 联讯仪器（国内龙头，份额9.9%）、伽蓝特（华盛昌子公司）等正在突破

**竞争格局**：

| 梯队 | 代表企业 | 特征 |
|------|----------|------|
| 国际巨头 | Keysight、Anritsu、Tektronix | 全品类覆盖，主导高端（65GHz+示波器） |
| 国内先行者 | 联讯仪器 | 1.6T全套方案量产，客户覆盖旭创/新易盛 |
| 并购切入者 | 华盛昌（伽蓝特）、优利德 | 通过并购快速获取能力 |
| 技术延伸者 | 普源精电、鼎阳科技 | 从通用仪器向光通信专用延伸 |

### 3.3 华盛昌的行业位置

```
                    ┌─────────────────────────────────────┐
                    │         光通信测试赛道（高增长）         │
                    │  联讯仪器 │ 伽蓝特(华盛昌) │ 优利德    │

华盛昌的独特之处在于：**传统仪器仪表基本盘提供现金流和渠道，伽蓝特提供高增长弹性，AI赋能提供估值溢价**——三者构成"稳+增+溢"的组合。

### 5.2 财务特征分析

**收入端：V型反转后再度承压**

```

- 2021–2022：疫情红利消退+海外需求回落，营收连续下滑
- 2023–2024：新产品放量+大客户战略见效，营收恢复增长
- 2025：中美关税升级+传统业务增速放缓，营收同比微降0.52%

**利润端：2025年显著承压**

2025年净利润同比大幅下降35.67%至0.89亿元，主要原因：
1. 中美关税升级影响出口业务
2. 管理费用同比+24.10%（合并范围增加+股份支付）
3. 销售费用同比+11.45%（市场投入增加）
4. 汇兑损益由正转负（财务费用从-814万变为-48万）
5. 经营现金流锐减73.39%至5979万元

**资产质量：稳健偏保守**

- 资产负债率24.75%（行业偏低），财务杠杆空间充足
- 但收购伽蓝特支付4.6亿元现金（首期9200万+并购贷款1.84亿），短期财务压力上升
- 2025年零分红（对比2024年10转4派7.3元），保留资金用于并购整合
